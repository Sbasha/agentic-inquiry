# ai Development Plugin

Development tools and guidelines for contributing to Agentic Inquiry.

## Skills

### Core Guidelines
| Skill | Description |
|-------|-------------|
| `coding-guidelines` | Parser constraints, logging, types, security, async patterns |
| `testing` | Test commands, fixtures, anti-patterns |
| `quality` | Quality checklists, fragile areas, fix-break prevention |
| `extending` | How to add parsers, tools, config, entity types |
| `plugins` | Gemini, OpenCode, Codex, Copilot integrations |
| `commit` | Pre-commit checks, session documentation |

### Review & Quality
| Skill | Description |
|-------|-------------|
| `test-quality` | Unit test anti-patterns and quality review |
| `doc-quality` | Documentation review checklist |
| `code-review` | Code logic and safety checklist |
| `rca` | Root cause analysis template |
| `cleanup` | Repository hygiene and maintenance |

## Commands

| Command | Description |
|---------|-------------|
| `sync-agents` | Synchronize AGENTS.md with skills |

## Usage

```
# Core guidelines
/ai-dev:coding-guidelines   # View coding standards
/ai-dev:testing            # View testing guidelines
/ai-dev:quality            # View quality checklists
/ai-dev:extending          # How to extend ai
/ai-dev:plugins            # CLI integrations
/ai-dev:commit             # Commit requirements

# Review & quality
/ai-dev:test-quality       # Unit test anti-patterns
/ai-dev:doc-quality        # Documentation review
/ai-dev:code-review        # Code review checklist
/ai-dev:rca                # Root cause analysis
/ai-dev:cleanup            # Repository cleanup
```
