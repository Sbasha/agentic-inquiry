# Reframe techniques

Use these techniques only when the material warrants them.
None is mandatory, and none should become a signature phrase or recurring template.

## Clarify the governing question

Write the question the current piece answers and the question the proposed piece would answer.
If they differ, the work is a reframe rather than a rewrite.

## Separate claim from stakes

State what the evidence supports separately from why the result matters.
Do not inflate the claim to make the stakes feel larger.

## Find the crux

Give an opposing case enough room to be recognizable.
Then identify the assumption, constraint, evidence, or value judgment that changes the answer.
Do not invent a vague adversary to create tension.

## Use a grounded example

Choose an example already supplied by the user or supported by a source.
Name what it establishes and what it does not establish.
Do not create a personal scene, composite character, customer, number, or quotation.

## Use analogy sparingly

Use an analogy only when it explains a mechanism more clearly than literal language.
Check where the analogy stops matching the subject.
One accurate analogy is stronger than a pattern of vivid but shallow comparisons.

## Scale implications carefully

Move from the bounded evidence to a broader implication only when the inference is explicit.
Label a working hypothesis, aspiration, or speculation rather than presenting it as a verified trend.

## Keep the ending proportional

End with the decision, implication, remaining uncertainty, or natural final observation.
Do not add a slogan, broad industry prediction, call to action, or sign-off unless the user and channel require it.
