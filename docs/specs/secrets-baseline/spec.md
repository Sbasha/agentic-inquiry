# Spec: Working pre-commit hooks with an audited secrets baseline

Mode: light (borderline - the change configures the secret-scanning gate, but
touches no runtime secret handling; a security-reviewer pass is added because
the baseline allowlists findings.)

- **Status:** Shipped (2026-09-26)

## Objective

`.pre-commit-config.yaml` runs detect-secrets v1.4.0 with
`--baseline .secrets.baseline`, but the baseline has never existed, so the hook
exits with `argument --baseline: Invalid path: .secrets.baseline` and anyone who
installs the hooks cannot commit. Add an audited baseline, make every hook pass
on files that already meet the repo's own format and lint rules, and tell
contributors to install the hooks.

## Acceptance Criteria

- [x] `.secrets.baseline` is generated by detect-secrets 1.4.0 (the hook's pinned
  version). Its only filters beyond the defaults are two line exclusions:
  digest fields (`revision` and `git_blob_oid` holding 40 hex characters,
  `sha256` holding 64), which cover the 138 digests in the OKF provenance
  packets and the two in the project-knowledge mutation fixture; and
  `rev: <40 hex>  # frozen: v...` lines in the pre-commit config. The rest of
  those files, including the verbatim upstream text in `original_utf8`, is
  still scanned.
- [x] Every baseline entry (30) was reviewed against its source line and carries
  `is_secret: false`; `detect-secrets audit --report --only-real` is empty.
- [x] A local `secrets-baseline-audited` hook rejects a baseline that holds an
  unaudited entry or one marked as a real secret, because `detect-secrets-hook`
  suppresses every baseline entry regardless of its label.
- [x] `uvx pre-commit run detect-secrets --all-files` passes.
- [x] A staged file containing a new fake secret is rejected by the installed
  commit hook.
- [x] The lifecycle contract test builds its private-key PEM header at runtime,
  so neither secret scanner needs a file exclusion or baseline entry for it, and
  a real key of any header type in that file is caught.
- [x] pre-commit-hooks is on v6.0.0, which uses current stage names, so the
  deprecated-stage warning is gone. Remote hooks are pinned to the commit behind
  their release tag.
- [x] The ruff hooks run `uv run --frozen ruff`, so they use the version locked in
  `uv.lock` and honor `pyproject.toml` excludes through `--force-exclude`.
- [x] `check-ast` skips only `tests/parsers/samples/corrupted.py` and
  `partial.py`, the two deliberately malformed fixtures, and the whitespace and
  line-ending fixers skip `tests/parsers/samples/`.
- [x] CONTRIBUTING.md Getting Started runs `uvx pre-commit install`, and the
  development workflow explains the hook's dependency on uv, how to handle a
  false positive, and what a baseline update from the hook means.

## Boundaries

Out of scope: the repo-wide ruff format sweep and the `scripts/finetune_model.py`
syntax error, which the `ruff-format-baseline` change fixes; pre-existing ruff
lint findings; and the items in
[`docs/backlog.md`](../../backlog.md#secrets-baseline) (whitespace debt and
secret scanning in CI). The lifecycle contract test file is not yet formatted
with ruff, so the `ruff-format` hook rewrites it until the format sweep lands.

## Tasks

1. Generate `.secrets.baseline` with the digest and frozen-rev line filters, and
   audit every entry.
2. Build the PEM header at runtime in the lifecycle contract test.
3. Update `.pre-commit-config.yaml`: audit hook, pinned revisions, ruff through
   uv, fixture excludes.
4. Document hook installation and the secret-scanning workflow in
   CONTRIBUTING.md; record the remaining debt in `docs/backlog.md`.

## Testing Strategy

Goal-based: every hook run in a scratch clone with the hooks installed, a real
`git commit` through the installed hook, negative tests that stage a fake AWS
key in a new file and in a provenance packet's `original_utf8`, a real PKCS#8
block in the lifecycle test, and baselines edited to hold an unaudited entry and
an entry marked real. The lifecycle contract test module is run to confirm the
runtime-built header keeps its behavior.
